# v0.4.0 Capability Expansion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Expand the public MCP surface from 46 to 56 tools with verified device writes, bounded discovery, safe Session operations, and backward-compatible capability improvements.

**Architecture:** New Live Object Model reads and mutations run through the existing TCP Remote Script UI-thread queue. `load_device_to_track` remains on the existing WebSocket route; `get_session_overview` is local composition. Contracts, models, registry, fakes, tests, and docs move together at every public-surface increment.

**Tech Stack:** Python 3.10+, FastMCP, Pydantic v2, Ableton Python LOM, pytest, Ruff, mypy strict, TypeScript Extension build.

**Lint configuration:** Ruff line length 100 and the repository's `pyproject.toml` rules; mypy `--strict` for `ableton_mcp_server`.
